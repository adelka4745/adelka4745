# UwpPortfolioApp

Это базовый каркас UWP/WinUI-приложения для личного портфолио, проектов, категорий и помощи по программированию.

## Что входит
- Главная вкладка
- Проекты
- Категории
- Языки программирования
- Вкладка "Помощь по программированию"
- Заметки
- Настройки
- Неоновый / cyberpunk стиль

## Как открыть в Visual Studio
1. Откройте папку `UwpPortfolioApp` в Visual Studio 2022.
2. Убедитесь, что установлен Windows App SDK / WinUI.
3. Откройте файл `UwpPortfolioApp.csproj`.
4. Запустите проект на Windows 10/11.
